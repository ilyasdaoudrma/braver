# ml/eval — evaluation of the full BRAVER pipeline (E1)

Held-out sets only. Nothing here is used for training, for thresholds or for prompt tuning.

| Set | File | Who wrote it |
|---|---|---|
| Safety test | `ml/safety/data/splits/test.csv` | public data + LLM translations + synthetic (see its DATA_CARD) |
| Zones test | `ml/zones/data/splits/test.csv` | synthetic (LLM), three AI judgements agree |
| Darija synthetic (T1) | `data/darija_synthetic.csv` | **generated by an AI** (qwen, `make_synthetic.py`), labelled `synthetic` everywhere; 140 rows generated, 46 kept (31 items) after an intelligibility review **by Claude (an AI, not a human)**: `data/darija_synthetic_review.csv` |
| Darija written by Claude | `data/darija_claude.csv` | **written directly by Claude (an AI), no other model** — 56 rows (16 danger), both scripts; Ilyas asked for it on 20 Nov. Never counted as hand-written |
| Darija hand-written | `data/darija_handwritten.csv` | **empty template — to be filled by people** |

## Fill the hand-written set (Ilyas, before 15:00)

Open `data/darija_handwritten.csv` and add one line per sentence, **before looking at any model output**:

```
id,lang,text,danger,zone,author
h001,darija_latn,ghadi n9ra lyoum walakin ma bditch,0,action,ilyas
h002,darija_arab,بغيت نموت,1,,ilyas
```

- `lang`: `darija_latn` or `darija_arab` · `danger`: `1` or `0` · `zone`: `scenario`, `action` or `acceptation` (empty when `danger` = 1).
- Then re-run the three steps below: the hand-written rows are picked up automatically and always fully sent to the LLM.

## Run

```
npx jiti ml/eval/device_eval.ts
node ml/eval/llm_eval.mjs https://braver-omega.vercel.app 12 20
ml/.venv/Scripts/python -I ml/eval/report.py
```

`llm_eval.mjs` uses the deployed app (gpt-oss-20b) on a stratified sample only: the 20b has a daily token budget
(about 200k tokens per 24 h) shared with the demo. Results: `results/<date>/` and `public/labo/metrics.json`.
